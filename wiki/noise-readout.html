Readout Chain Noise Vector

Amplifier and generator noise mapped into source-vector form.

Physical Expressions

Input-referred sideband voltages:

\[V_A=\sqrt{k_B T_A Z_0},\qquad V_G\approx |S_{21}|\sqrt{k_B T_G Z_0}.\]

The active model includes amplifier noise through \(T_A\) (default \(1.3\,\mathrm{K}\)) and uses \(Z_0=50\,\Omega\) at the readout reference plane.

Noise Vector Derivation

The code builds amplifier modes in sideband form first:

\[ n_{\mathrm{amp},A}^{SB}=\frac{V_A}{\sqrt{2}} \begin{bmatrix}1\\1\\0\\0\end{bmatrix}, \qquad n_{\mathrm{amp},\phi}^{SB}=\frac{V_A}{\sqrt{2}} \begin{bmatrix}-1\\1\\0\\0\end{bmatrix}. \]

Using the readout-circle radius

\[ r_V=\frac{\sqrt{P_0Z_0}}{2}, \]

the sidebands are mapped to normalized readout coordinates \([r,\phi]\). This reproduces the matched-resonator estimate

\[ \sigma_{\mathrm{amp}}=\frac{\sqrt{2}V_A}{r_V}=\sqrt{\frac{8k_BT_A}{P_0}}. \]

The implementation compares SB-derived vectors to the closed-form vectors \(N_{\mathrm{amp},A}=[\sigma_{\mathrm{amp}},0,0,0]^T\) and \(N_{\mathrm{amp},\phi}=[0,i\sigma_{\mathrm{amp}},0,0]^T\), and raises if they disagree.

Integration Into Model

Correct treatment for this linear 2-KID model: amplifier noise is additive measured readout noise in \(r/\phi\). If heater feedback is enabled, the same measured phase noise also drives the feedback heater, so the direct measurement term and heater-return term are correlated and must be solved together as one complex transfer.

This is different from adding an independent heater-noise PSD after the fact. The heater-return signal is not a new uncorrelated noise source; it is the controlled plant response to the same amplifier phase fluctuation already present in the measured output.

For a measured readout-noise realization \(q=[q_r,q_\phi]^T\), the device response is solved with the heater-feedback source

\[ N_{\mathrm{fb,amp}}= \begin{bmatrix} 0\\0\\0\\ \left(K_p+i\omega K_d\right)q_\phi \end{bmatrix}. \]

The measured output is then \(Y_{\mathrm{meas}}=M^{-1}N_{\mathrm{fb,amp}}+[q_r,q_\phi,0,0]^T\). This allows partial cancellation or enhancement depending on loop sign, gain, and frequency.

Two independent amplifier modes are included, \(q_A=[\sigma_{\mathrm{amp}},0]^T\) and \(q_\phi=[0,i\sigma_{\mathrm{amp}}]^T\). Their solved phase PSD contributions are added in quadrature with Johnson, phonon, TLS, and electronic noise:

\[ S_{\phi,\mathrm{total}}=S_{\phi,J}+S_{\phi,\mathrm{TLS}}+S_{\phi,\mathrm{ph}}+S_{\phi,e}+S_{\phi,\mathrm{amp}}. \]

Do not add a separate external amplifier PSD block unless this internal amplifier path is disabled.

Physical Scope

This treatment is physically consistent for the present small-signal model under these assumptions:

  • The feedback controller senses phase only, so \(q_\phi\) drives the heater and \(q_r\) enters directly as amplitude readout noise.
  • The feedback heater command is linear, \(K_p+i\omega K_d\), with no saturation, quantization, DAC/ADC noise, or additional electronics delay.
  • The actuator thermal dynamics are the island-2 thermal dynamics already represented inside \(M(\omega)\).
  • The amplifier is represented by white input-referred noise temperature \(T_A\) at a matched \(50\,\Omega\) readout plane.

A more complete readout/control model would add independent controller electronics noise, loop delay and filters, heater-current noise, actuator nonlinearity, and feedline loss or mismatch. Those effects should be added as separate correlated or uncorrelated paths only when their physical reference planes are specified.
